I’d actually separate these internally into orthogonal properties, because then you can combine them.

For example:

Harmony: tetradic
Temperature: warm
Mood: muted
Value: dark

That could produce Warm + Muted + Dark + Tetradic, rather than forcing the user to choose one giant preset.

The useful axes would probably be:

Temperature: Warm / Neutral / Cool
Chroma: Muted / Natural / Vibrant / Neon
Value: Pastel / Light / Balanced / Deep / Dark
Character: Earthy / Dusty / Romantic / Moody / Playful / Elegant / Vintage / etc.

That gives you a surprisingly powerful palette system. A request like “standard magenta, tetradic, warm, dusty, deep” becomes completely deterministic enough to generate programmatically while still sounding like how a human would describe the palette.
